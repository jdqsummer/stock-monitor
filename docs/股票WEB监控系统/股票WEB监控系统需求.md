## 用户需求
### 概述
开发一款AI企业价值和安全边际判断的股票监控系统。对个人市值和盈亏分析，对持仓、自选股票的基本面、企业价值、安全边际分析和监控。同时对提供的企业和相关企业信息，对企业进行系统分析，给出企业的判断价值判断标准、安全边际等信息，辅助用户选股，以及投资策略。

### 产品功能
仪表盘，监控总市值、持仓股、自选股。
- 支持自选股票。自选股票可以按企业所属行业进行分类，支持智能一键分类和用户手动分类。
- 自选的股票实时安全边际监控看板。比如30min实时分析企业的安全边际，如果当前的市值和价格在安全边际范围，显示绿灯；如果在安全边际上限30%，显示黄灯；如果在安全边际上限的30%以上红灯。
- 自选股呈现实时的股票信息，包括股票名称、年化净利、击球区PE、击球区市值、对应股价、当前市值、当前股价、距击球区。点击自选股，可以看到更详细的信息。
- 持仓分析。总市值、总盈亏、持仓数量、盈利数/亏损数、当日盈亏。
- 持仓股。企业名、盈亏（金额/比例）、持有数量、成本价/现价、当日盈亏、个股持仓比例、距击球区、所属行业。

支持记录投资笔记，作为用户投资分析的经验输入模型。
- 安全边际分析（分析agent）。用户输入企业，以及相关信息，对企业进行价值和安全边际分析。内置一套投资分析体系，作为AI的分析框架，通过这套分析体系，调用工具获取实时数据和财报，进行系统性分析，给出企业的商业模式、安全边际和投资价值建议。采用 Harness 进行投资框架约束。
	```
	用户输入企业信息 → 分析Agent
  → 记忆检索（L3 用户投资画像 + L2 关注行业）
  → 工具调用：连接腾讯自选股 MCP（westock-mcp）
    - 行情数据 API（实时价格/历史K线）
    - 财报数据 API（营收/利润/ROE等）
    - 新闻搜索 API（公司近期动态）
    - 技术指标计算（云端沙箱执行）
  → LLM 采用价值体系框架分析 → 输出选股建议
  → 记忆回写（用户关注的股票 → L1）
	```
- 对话分析（聊天Agent）。价值投资聊天Agent，基于价值投资角色和体系与用户聊天
	```
	用户对话 → 通用聊天Agent
  → 记忆检索（全层级）
  → 对话响应
  → 实时流式输出 (SSE)
  → 对话结束 → 异步蒸馏
    - 提取事实/偏好 → L1
    - 更新场景知识 → L2
    - 定期更新用户画像 → L3
	```
- 投资笔记（日记Agent）。用户可以记录自己的投资决策和总结、心理思考和行为活动，用于AI分析，判断投资行为的分析和建议。建立理性的投资行为。```
```
用户写日记 → 日记Agent接收
  → 提取投资决策（买入/卖出/观察）
  → 结构化存储（标的、价格、理由、情绪）
  → 写入 L0 对话记录
  → 异步蒸馏到 L1（投资偏好）→ L2（投资策略）→ L3（投资画像）
  → Agent 点评日记，提供理性反馈
```

### 关于持仓分析

- 距击球区，改为卖出价格。需要通过DSH，对持仓股票进行定性分析，给出卖出的价格。
- 添加删除操作列，类似自选股。

2、支持持仓股分析。整体的调用分析流程跟DSH的五段分析流程和页面呈现效果保持一致，但需要更改几点：
- 注入基本数据处理跟dataSummary原始数据一致外，需要增加持有数量、成本价和市值。
- 新增一个卖出定性分析流程，注入：持仓股基本数据+卖出原则+定性分析+逆向分析结论+ 全部 evidence。
- 卖出原则，有以下4种情况：生成对应的skill。
(1)发现买错了，这不用说，要立即改正。商业模式和经营质量差、完全没有安全边际等。
(2)公司基本面发生根本性变化。根本性变化是指公司的竞争地位被取代、商业模式被颠覆、提供的产品和服务已过时等，一时的增长放缓当具体研判。若公司出现超预期的负面变化（如管理层变动、行业政策利空、财务状况恶化），导致内在价值永久性下降，需果断卖出以规避风险。
(3)内在价值被高估：当资产价格显著高于其内在价值（如市场过度乐观、估值泡沫化），需考虑卖出以锁定利润。价值投资者的核心逻辑是“买得好”，价格远离内在价值时即触发卖出信号。
(4)股价太疯狂。疯狂程度可结合市场整体牛熊进行具体研判。创新高，并且换手率达到15%以上。
以上4种情况下的卖出，是顺理成章的事情，但一定要坚决规避两种卖出情况：
一是被大跌“吓”得卖出。这种被吓的卖出往往是愚蠢的卖出。若下跌是市场非理性恐慌导致的短期错杀，且公司基本面未变（内在价值未受损），价值投资者反而会“向下摊平”加仓，而非卖出。核心原则 ：卖出决策需基于对内在价值的精准判断，避免情绪化操作。正如马克斯所言，成功的关键在于“正确分析”和“坚定信心”，而卖出是修正错误或捕捉更高价值的必要行动。
二是“乐”得卖出。投资者认为赚了钱，比如赚了百分之几十，或者翻倍了，就乐得卖出。这种卖出，实际上是一种糊涂的卖出。
- 前端显示变化，将4. 安全边际分析 改变 为卖出分析。去掉安全边际分析显示，替换为卖出分析，字段统一改为，卖出PE区间和理由、卖出市值区间和对应的股价、距卖出区和信号。去掉年化利润和利润口径。
- 最后给出总结与建议
先给出结论，在给出行动建议。继续持有还是卖出，如果是卖出，给出卖出的行动建议。
