## 用户需求
### 概述
开发一款AI企业价值和安全边际判断的股票监控系统。对个人市值和盈亏分析，对持仓、自选股票的基本面、企业价值、安全边际分析和监控。同时对提供的企业和相关企业信息，对企业进行系统分析，给出企业的判断价值判断标准、安全边际等信息，辅助用户选股，以及投资策略。

### 产品功能
仪表盘，监控总市值、持仓股、自选股。
- 支持自选股票。自选股票可以按企业所属行业进行分类，支持智能一键分类和用户手动分类。
- 自选的股票实时安全边际监控看板。比如30min实时分析企业的安全边际，如果当前的市值和价格在安全边际范围，显示绿灯；如果在安全边际上限30%，显示黄灯；如果在安全边际上限的30%以上红灯。
- 自选股呈现实时的股票信息，包括股票名称、年化净利、击球区PE、击球区市值、对应股价、当前市值、当前股价、距击球区。点击自选股，可以看到更详细的信息。
- 持仓分析。总市值、总盈亏、持仓数量、盈利数/亏损数、当日盈亏。
- 持仓股。企业名、盈亏（金额/比例）、持有数量、成本价/现价、当日盈亏、个股持仓比例、距击球区、所属行业。

支持记录投资笔记，作为用户投资分析的经验输入模型。
- 安全边际分析（分析agent）。用户输入企业，以及相关信息，对企业进行价值和安全边际分析。内置一套投资分析体系，作为AI的分析框架，通过这套分析体系，调用工具获取实时数据和财报，进行系统性分析，给出企业的商业模式、安全边际和投资价值建议。采用 Harness 进行投资框架约束。
	```
	用户输入企业信息 → 分析Agent
  → 记忆检索（L3 用户投资画像 + L2 关注行业）
  → 工具调用：连接腾讯自选股 MCP（westock-mcp）
    - 行情数据 API（实时价格/历史K线）
    - 财报数据 API（营收/利润/ROE等）
    - 新闻搜索 API（公司近期动态）
    - 技术指标计算（云端沙箱执行）
  → LLM 采用价值体系框架分析 → 输出选股建议
  → 记忆回写（用户关注的股票 → L1）
	```
- 对话分析（聊天Agent）。价值投资聊天Agent，基于价值投资角色和体系与用户聊天
	```
	用户对话 → 通用聊天Agent
  → 记忆检索（全层级）
  → 对话响应
  → 实时流式输出 (SSE)
  → 对话结束 → 异步蒸馏
    - 提取事实/偏好 → L1
    - 更新场景知识 → L2
    - 定期更新用户画像 → L3
	```
- 投资笔记（日记Agent）。用户可以记录自己的投资决策和总结、心理思考和行为活动，用于AI分析，判断投资行为的分析和建议。建立理性的投资行为。```
```
用户写日记 → 日记Agent接收
  → 提取投资决策（买入/卖出/观察）
  → 结构化存储（标的、价格、理由、情绪）
  → 写入 L0 对话记录
  → 异步蒸馏到 L1（投资偏好）→ L2（投资策略）→ L3（投资画像）
  → Agent 点评日记，提供理性反馈
```

### LLM + 外部数据源
- 股票数据源：连接腾讯自选股 MCP（westock-mcp），获取实时行情拉取、自选股账号同步、自然语言交互数据获取、基础投研辅助等数据。 提供页面配置，包括更新频率、个人信息。
- LLM： 自然语言分析支持千问、DeepSeek、GLM、Kimi等模型选择和相关配置。
- Harness框架：采用OpenHarness框架 [OpenHarness/README.zh-CN.md at main · HKUDS/OpenHarness](https://github.com/HKUDS/OpenHarness/blob/main/README.zh-CN.md)执行价值分析。
- 价值投资体系：所有安全边际分析、基本面和价值分析都是基于内置的价值投资体系的Harness框架分析的结果。分析框架 [[投资分析框架]]。
- 更新频率：价值体系分析更新频率可配置，比如：早上或下午收盘更新。

### 需求灵感输入

penHarness 智能体内部如何执行分析（集成 LLM + 清单的方式）？

❯ 1. 结构化多阶段（推荐）
     固定流程：数据摘要 → 14道逆向清单(LLM结构化输出) → 定性分析(商业模式/护城河/风险) → 约束引擎校验 → 综合结论。每阶段
     LLM 输出 JSON 可校验，稳定可控。
  2. ReAct 自主循环
     LLM 自主决定分析步骤、逐步工具调用（类似 Claude Code/DataAgent.collect_with_llm 模式）。灵活但结果不可预测。
  3. 混合
     框架化多阶段为主，关键阶段（如清单证伪）允许 LLM 自主探索补充。
