# 股票WEB监控系统 — 设计语言规范

> **版本:** v1.0 | **日期:** 2026-08-08 | **状态:** 已确认

## 一、设计总纲

### 1.1 视觉风格

**Dark Bloomberg 金融终端风格** — 深色背景为基础，高对比度数据展示，冷峻专业感。

- 底色：深黑/深灰基调，减少视觉疲劳，适合长时间盯盘
- 强调：高亮数据以高饱和色彩呈现，关键指标醒目
- 密度：高信息密度布局，Bloomberg 终端式的「一屏全览」
- 动效：克制微动效，数据刷新以数值闪烁或微光扫过（辉光扫过）提示更新

### 1.2 色彩体系

**Dark Vercel 三态色彩体系** — 以中性灰色为基底，三态色彩承载信息层级。

| 色彩角色 | 用途 | 说明 |
|----------|------|------|
| 中性灰阶 | 背景、边框、文字层级 | 从 `#000` 到 `#fff` 的 12 级灰阶，Dark Mode 核心 |
| 强调色（Accent） | 主按钮、选中态、链接 | Vercel 蓝 `#0070F3` 或 Bloomberg 橙 `#FF6B00`（待定） |
| 三态信号色 | 数据状态编码 | 见下方「涨跌与信号灯」 |

### 1.3 字体系统

| 用途 | 字体 | 后备 |
|------|------|------|
| UI 正文 / 标题 | **Inter** | system-ui, -apple-system, sans-serif |
| 中文字体 | **Noto Sans SC** | Microsoft YaHei, PingFang SC, sans-serif |
| 数据 / 代码 / 表格数字 | **JetBrains Mono** | Consolas, Monaco, monospace |

- 表格中的数字（价格、市值、百分比）统一使用 `JetBrains Mono` 等宽字体，数字对齐
- 中文内容（分析报告、聊天、日记）使用 `Noto Sans SC`
- UI 控件、标题、标签使用 `Inter`

## 二、关键设计决策

### 2.1 涨跌色彩：中国股市惯例

> ⚠️ **核心规则：涨 = 红，跌 = 绿。与西方/国际惯例相反。**

| 方向 | 颜色 | HEX | 语义 |
|------|------|-----|------|
| 上涨 | 🔴 红 | `#EF4444` / `#DC2626` | 盈利、正收益 |
| 下跌 | 🟢 绿 | `#22C55E` / `#16A34A` | 亏损、负收益 |
| 平盘 | ⚪ 灰 | `#9CA3AF` | 无变化 |

**适用场景：**
- 价格变动、涨跌幅
- 盈亏金额 / 百分比
- K线图（阳线红、阴线绿）
- 持仓盈亏显示

### 2.2 安全边际信号灯：质量评估色彩

> ⚠️ **与涨跌色不同体系！信号灯表示「距离理想买点的距离」，绿 = 好（在击球区），红 = 差（远离击球区）。**

| 信号 | 颜色 | HEX | 条件 | 含义 |
|------|------|-----|------|------|
| 🟢 绿灯 | 绿 | `#22C55E` | `distance_pct ≤ 0%` | 已在击球区内 → 可配置/买入 |
| 🟡 黄灯 | 黄/橙 | `#F59E0B` | `0% < distance_pct ≤ 30%` | 观察区 → 等待时机 |
| 🔴 红灯 | 红 | `#EF4444` | `distance_pct > 30%` 或亏损企业 | 高估区 → 暂不配置 |

**两个色彩体系互不干扰的原则：**
1. 涨跌色用在**实时行情**数据上（价格、百分比变动）
2. 信号灯色用在**安全边际评估**上（距击球区距离）
3. UI 中通过**位置和上下文**区分：涨跌在行情卡片/表格列，信号灯在专属「信号」列/Badge
4. 当同一股票同时展示涨跌和信号时，信号灯以独立 Badge/Tag 呈现，涨跌以文字颜色呈现

## 三、组件规范

### 3.1 表格（核心数据展示）

- 表头固定，内容区可滚动
- 数字列右对齐，等宽字体 `JetBrains Mono`
- 涨跌列使用红绿色区分
- 信号灯列使用独立 Badge/Tag
- 行悬停高亮（微弱亮度提升）
- 点击行可展开详情或跳转

### 3.2 卡片（总览指标）

- 深色背景 + 微弱边框
- 指标名（小字、低对比度）在上，数值（大字、高对比度）在下
- 辅以趋势箭头（涨↗红、跌↘绿）
- 可配置显示/隐藏的迷你趋势图

### 3.3 信号灯 Badge

```tsx
// 三种信号灯样式
🟢 击球区    — 绿底 + 深绿文字 + 绿色边框
🟡 观察区    — 黄底 + 深黄文字 + 黄色边框
🔴 高估区    — 红底 + 深红文字 + 红色边框
```

### 3.4 按钮与交互

- 主操作按钮：强调色（待定蓝/橙）
- 危险操作（删除、清仓）：红色警示
- 数据刷新：手动刷新按钮 + 自动倒计时
- 加载态：骨架屏（Skeleton）优于转圈（Spin）

## 四、实现指南

### 4.1 CSS 变量体系（Tailwind 扩展）

```css
:root {
  /* 背景灰阶 */
  --bg-primary: #0A0A0A;
  --bg-secondary: #141414;
  --bg-tertiary: #1A1A1A;
  --bg-card: #1F1F1F;
  --bg-hover: #2A2A2A;

  /* 边框 */
  --border-primary: #2E2E2E;
  --border-secondary: #3A3A3A;

  /* 文字 */
  --text-primary: #FAFAFA;
  --text-secondary: #A1A1AA;
  --text-tertiary: #71717A;

  /* 涨跌色彩（中国惯例） */
  --color-up: #EF4444;        /* 涨=红 */
  --color-down: #22C55E;      /* 跌=绿 */
  --color-flat: #9CA3AF;      /* 平=灰 */

  /* 信号灯色彩 */
  --signal-green: #22C55E;    /* 击球区 */
  --signal-yellow: #F59E0B;   /* 观察区 */
  --signal-red: #EF4444;      /* 高估区 */
}
```

### 4.3 数字格式化约定

| 场景 | 格式 | 示例 |
|------|------|------|
| 股价 | `¥{n}.{00}` | `¥1,234.56` |
| 市值（亿） | `{n,}亿` | `12,345亿` |
| 百分比 | `{±n}.{00}%` | `+3.45%` / `-2.10%` |
| 金额（万） | `{±n,}.{00}万` | `+1,234.56万` |
| 数量 | `{n,}` | `12,345` |
| 散股 | `{n}` | `500` |
