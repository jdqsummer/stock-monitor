# 记忆机制与 L1/L2/L3 蒸馏管道

> 系统分层记忆架构 + 蒸馏各层级的具体动作说明。
> 日期：2026-08-24

---

## 一、记忆机制总览

系统记忆是**四级分层**（L0→L3），存 SQLite，涉及两张表：

| 层级 | 含义 | 落库表 | 谁写 |
|:--|:--|:--|:--|
| L0 | 原始对话记录 | `conversations`（messages JSON） | Chat / Diary Agent 每轮 |
| L1 | 结构化事实与偏好 | `memories`(level=L1) | 蒸馏管道 |
| L2 | 行为 / 策略模式归纳 | `memories`(level=L2) | 蒸馏管道 |
| L3 | 用户投资画像（全文） | `memories`(level=L3) | 画像合成 |

`memories` 每条含 `level / category / content / source / confidence`（见 `backend/models/memory.py`），`confidence` 用于检索加权。

### 三条链路

- **写（蒸馏触发）**：Chat Agent 对话结束 → `chat_agent_loop.py` 调 `MemoryService.distill_async()`（后台异步任务，不阻塞响应，见 `backend/services/memory_svc.py`）；Diary Agent 同样调蒸馏（`diary_svc.py`）。L3 画像定期 / 触发式重建（`chat_context.py`、`update_L3_profile`）。
- **读（检索）**：`MemoryRetriever.build_context()`（`backend/memory/retrieval.py`）按 query 分三层检索后拼成注入 prompt 的上下文。
- **CRUD**：`MemoryStore` 全部方法需 `AsyncSession`（经 `get_db()` 注入），提供 `save_memory / update_memory / upsert_memory_by_category / delete_memory`。蒸馏落库统一走 **upsert 按 (level, category) 去重**。

### 检索分层策略（`retrieval.py`）

- **L1**：关键词 + category 精确匹配，分数再乘 confidence（`_keyword_score`）
- **L2**：`difflib.SequenceMatcher` 字符串相似度排序（`_similarity_score`）
- **L3**：直接返回画像全文
- 检索上限：L1=20 / L2=10 / L3=1

## 二、蒸馏 L1/L2/L3 的具体动作

生产路径走 **`backend/memory/distillation.py` 的 `DistillationPipeline`**（LLM 驱动，模型 `deepseek-chat`）。`backend/agents/memory_workflow.py` 是 Plan-4 的 LangGraph 版（含纯规则降级），未被 MemoryService 引用，属遗留路径。

### L1 事实提取（`distill_conversation` 第一步）

1. 对话文本截断到前 4000 字，喂 `L1_EXTRACTION_PROMPT`
2. LLM 按 `category | content` 每行一条输出，category 限定五种：**关注行业 / 关注股票 / 投资偏好 / 风险偏好 / 个人约束**
3. 逐行解析（`split("|", 1)`），跳过"无"
4. 逐条 `upsert_memory_by_category` 写入：level=L1、`source="distillation"`、**confidence=0.7**
5. 单条失败不影响整体（try/except 记日志）

### L2 策略归纳（第二步）

1. 同样取前 4000 字，喂 `L2_STRATEGY_PROMPT`
2. LLM 输出 ≤200 字的一段总结，覆盖四点：**选股模式 / 交易习惯（追涨/抄底/定投/分批）/ 决策风格 / 行为偏差（过度交易/锚定/损失厌恶/确认偏差）**
3. 以整段写入**一条**记忆：level=L2、category=固定"投资策略"、**confidence=0.6**

### L3 画像合成（`build_L3_profile`，独立入口）

1. 读取最新 **50 条 L1 + 20 条 L2** 拼成 prompt
2. LLM 按 `L3_PROFILE_PROMPT` 输出 ≤300 字画像，含五项：**投资风格标签（价值/成长/均衡/投机）、风险承受度（保守/稳健/激进）、关注行业 Top3、行为模式特征、需警惕的认知偏差**
3. `upsert_memory_by_category` 写入：level=L3、category="投资画像"、**confidence=0.8**（更新式覆盖旧画像）
4. 无 L1/L2 数据时返回 `"暂无足够数据"` 不生成

### 遗留 LangGraph 版（`memory_workflow.py`）

节点链 `L1事实提取 → L2模式归纳 → L3画像生成 → 冲突检测 → 存储结果`：

- 无 LLM 时走**纯规则**：行业 / 偏好关键词匹配提取事实 → 按 category 聚合归纳模式 → 规则合成画像
- 多出一步**冲突检测**：对比新旧 L3 的 `style`、`risk_tolerance`，变化即记 conflict（风格变更"以新为准"；风险变更"标记待用户确认"）

---

## 三、要点小结

- **数据流**：对话(L0) → 异步蒸馏出 L1/L2 → 定期合成 L3 → 检索时 L3(全文) + L2(相似) + L1(关键词) 注入 Agent prompt
- **去重与权重**：L1/L2/L3 落库均 upsert；confidence 递减（L1=0.7 → L2=0.6 → L3=0.8），检索排序按 confidence × 匹配度
- **降级**：蒸馏失败静默记日志不阻断；LLM 不可用时生产路径不可用，只有遗留规则版可兜底
