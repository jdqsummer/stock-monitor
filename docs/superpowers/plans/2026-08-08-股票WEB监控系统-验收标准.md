## 一、验收标准格式规范

每条验收标准遵循统一格式：

| 字段 | 说明 |
|------|------|
| 编号 | `AC-{Plan}-{序号}`，如 `AC-1-03` = Plan-1 第3条 |
| 验收项 | 一句话描述要验证什么 |
| 验收标准 | 可度量的通过条件（必须二值化：通过/不通过） |
| 验证方法 | 具体操作步骤（命令、URL、脚本、观察点） |
| 优先级 | P0=阻塞上线 / P1=应在迭代内完成 / P2=可延后 |

**二值化原则：** 所有验收标准必须是"是/否"判断，不允许"部分通过"、"大致完成"等模糊表述。无法二值化的标准应拆分为多个子标准。

**独立性原则：** 每条标准可独立验证，不依赖其他标准的验证结果。如果标准 A 依赖标准 B，则合并为一条。

  # 4. 前端请求 API 并渲染
  ```
- **优先级:** P1（集成测试阶段）

**AC-X-05: 安全边际计算 → 分析快照 → 监控看板链路贯通**

- **验收标准:** MarginEngine.calculate() → 写入 analysis_snapshots 表 → Dashboard API 查询 → SignalBoard 组件渲染
- **验证方法:** 端到端测试：创建分析快照 → 查询 dashboard/watchlist-status → 验证 SignalBadge 颜色正确
- **优先级:** P0

**AC-X-06: Agent 分析结果回写记忆链路贯通**

- **验收标准:** 分析 Agent 完成分析 → step_write_memory 写入 L1 记忆 → MemoryRetriever 可检索到
- **验证方法:** 集成测试：运行一次分析 → 检索该用户的 L1 记忆 → 验证存在对应条目
- **优先级:** P1（Plan-4 + Plan-5 联合测试）

**AC-X-07: 用户配置变更反映到 Agent 行为**

- **验收标准:** 修改 llm_model 为 qwen-max → Agent 使用 QwenProvider；修改 data_refresh_interval → 定时任务间隔更新
- **验证方法:** 集成测试：修改配置 → 验证 Agent 使用正确 Provider → 验证 Scheduler 间隔正确
- **优先级:** P1

### 8.2 安全（AC-NF-03 ~ AC-NF-05）

**AC-NF-03: 密码 bcrypt 哈希存储**

- **验收标准:** 数据库 users 表中 password_hash 字段不以明文存储，以 `$2b$` 开头
- **验证方法:**

  ```

**AC-NF-04: JWT Secret 来自环境变量而非硬编码**

- **验收标准:** backend/config.py 中 JWT_SECRET_KEY 从环境变量读取，默认值仅用于开发；生产环境必须覆盖
- **验证方法:**
  ```bash

  # 验证 .env.example 中有明确注释要求修改
  ```
- **优先级:** P0

**AC-NF-05: API Key 不在日志/响应中暴露**

- **验收标准:** westock_api_key 和 LLM API Key 在日志中脱敏（显示前4后4位），在 API 响应中不返回完整值
- **验证方法:** 代码审查 api/config.py 是否在返回时过滤敏感字段

## 九、验收执行流程

### 9.1 单 Plan 验收流程

```
1. 环境准备
   ├── git checkout feature/plan-N
   ├── pip install -r requirements.txt
   └── cd frontend && npm install

2. 自动化测试
   ├── pytest tests/ -v --tb=short
   └── cd frontend && npm run build

3. 验收标准逐条验证
   ├── 按本文档优先级 P0 → P1 → P2
   ├── 每条标准记录 PASS/FAIL
   └── P0 全部通过 = 验收通过

4. 集成验证
   ├── docker-compose up -d
   ├── curl 端点冒烟测试
   └── docker-compose down
```

### 9.2 全系统验收流程

按实施顺序逐个 Plan 验收：

```
Plan-1 验收 → Plan-2 验收 → Plan-3 验收 (基础页面)
                              ↘ Plan-5 验收 (可并行)
                                   ↘ Plan-4 验收
                                        ↘ 全系统集成验收
```
