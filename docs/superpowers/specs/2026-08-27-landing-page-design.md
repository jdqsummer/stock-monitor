# Stock Monitor 宣传落地页设计

> **日期:** 2026-08-27 | **状态:** 已确认 | **类型:** 营销内容交付物

## 一、背景与目标

产品已上线生产（http://49.232.171.206），需一份宣传手册用于推广、吸引新用户注册使用。经澄清，交付物形态为**精美网页落地页**（自包含 HTML），分发主场景为**朋友圈/社群裂变**（移动端为主）。

**核心主张（来自产品定位）：** 好价格下的好公司。AI 驱动的 A 股安全边际分析平台。

## 二、关键约束（已确认）

| 项 | 决策 |
|:--|:--|
| 输出形式 | 单文件静态网页落地页（内联 CSS + 轻量 JS） |
| 目标受众 | 价值投资者（专业口径：扣非、PE 锚定、安全边际、逆向清单） |
| 分发渠道 | 朋友圈/社群裂变 → 移动端优先响应式 |
| 注册 CTA | 按钮直接跳转 `http://49.232.171.206` |
| 视觉基调 | 品牌色 `#4D6EFE` 浅色 DeepSeek 风（与产品一致） |
| 截图策略 | **A+B 混合**：真实截图（仅公共分析内容）+ CSS 手绘界面示意 |
| **数据脱敏** | **硬约束**：零个人数据暴露（详见第五节） |
| 部署方式 | 生产 nginx 独立路径 `/about`（不替换现有 SPA 首页） |

## 三、方案选型

**方案 A + B 混合（已确认）**：单文件静态落地页为主体，嵌入真实产品截图（仅公共分析内容），其余界面 CSS 手绘示意。权衡：既保留「真实产品分析能力」可信度，又保持单文件可分享、可部署、可迭代。

2. **痛点共鸣**：散户三大困境（凭感觉买卖 / 追高被套 / 缺乏纪律）→ 产品解法（价值投资方法论工程化为 AI 流水线）
3. **核心功能**（图文并茂）：
   - DSH 五段式分析（定性 → PE 锚定 → 击球区 → 逆向清单 → 结论）— 配真实截图
   - 三色信号灯实时看板（🟢 击球区 / 🟡 观察区 / 🔴 高估区）— CSS 手绘

5. **数据能力**：腾讯/东财多渠道源、A股+港股、30min 刷新 + 16:00 收盘重算

7. **CTA 收尾**：注册按钮 → `http://49.232.171.206`

## 五、数据脱敏方案（硬约束）

**核心原则：真实截图只取「公共分析内容」，涉及个人数据的界面一律 CSS 手绘，从源头规避隐私泄漏。**

### 5.1 真实截图（仅 1 张）

- **五段分析详情页**：某只股票（如贵州茅台 600519）的分析报告——护城河、风险、逆向清单、结论。属公共投资分析，非个人数据
- 采用 **Playwright 元素级截图**（只截分析内容区），避开顶部栏邮箱、侧边栏用户身份信息
- 截图前校验页面无任何个人数据（邮箱/用户名/自定义备注）

### 5.2 明确不截图（CSS 手绘示意）

| 界面 | 原因 |
|:--|:--|
| 仪表盘（总市值/盈亏/持仓面板） | 真实持仓与盈亏金额 = 个人隐私 |
| 持仓列表 | 成本价/持有市值/盈亏比例 = 个人隐私 |
| 自选股看板 | 个人选股组合 = 隐私（信号灯逻辑用手绘示意） |
| 聊天页 | 对话内容 = 隐私 |

### 5.3 手绘示意脱敏规范

- 示例股票用知名蓝筹（贵州茅台、五粮液、宁德时代、腾讯、长江电力等），数字一律为**演示值**（如"距击球区 -12%"、"PE 13-16"）
- 任何位置不出现真实邮箱、用户名、真实持仓金额
- 手绘数字与真实生产数据无对应关系

## 六、视觉风格

- 品牌色 `#4D6EFE`（primary）浅色系；信号灯三色 green `#52c41a` / yellow `#faad14` / red `#ff4d4f`；A 股惯例红涨绿跌
- 系统字体栈（`system-ui, -apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif`），**无外部字体/CDN 依赖**（离线可开、分享稳定）
- 圆角卡片 + 柔和阴影 + 品牌色渐变背景；克制微动效（滚动入场）
- 移动端优先响应式（flex/grid + media queries，断点 ~768px）
- 页面宽度限制 ~1080px 居中，长滚动叙事

## 七、技术实现与文件结构

```
docs/宣传手册/
├── landing.html              # 落地页（内联 CSS + 轻量 JS，零外部依赖）
├── screens/
│   └── five-stage-analysis.png   # 真实截图（仅公共分析内容，脱敏）
└── README.md                 # 使用说明（本地预览/部署到 /about 的步骤）
```

- 截图存为独立 PNG 文件（相对路径引用），不 base64 内联（控制 html 体积与 git 友好度）
- JS 仅用于：滚动入场动画（IntersectionObserver）、移动端锚点平滑滚动
- html 双击本地可预览；部署时 `landing.html` + `screens/` 一起放入 nginx 静态目录

## 八、成功标准

- 落地页在手机（375px~430px）与桌面端均排版正常、无横向滚动
- 页面零个人数据暴露（无邮箱/用户名/真实持仓/真实盈亏）
- 注册 CTA 可达（跳转 `http://49.232.171.206`）
- 单文件离线可打开，无外部资源失败
- 文案覆盖 8 项投资原则与核心卖点，专业口径无事实错误

## 九、非目标

- 不修改产品 SPA 首页/现有路由（落地页为独立 `/about`）
- 不做多语言版本
- 不做付费/套餐定价页（当前无定价概念）
- 不采集访问者信息（无埋点、无表单）
